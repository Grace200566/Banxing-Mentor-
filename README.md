# 伴行導師｜新任主管 AI 教練

> 管理路上雙向同行，從容扎根成長的陪伴者

## 產品介紹

「伴行導師」是專為新任主管設計的 AI 教練，聚焦**角色轉變**模塊，陪伴新主管完成從「明星球員」到「球隊教練」的心理與行為轉型。

### 四層完整體驗
- **心法** → 讓你想通「為什麼要改變」
- **方法** → 給你「怎麼做」的框架
- **話術** → 給你現在就能說出口的工具
- **演練** → 陪你在安全的地方練到有肌肉記憶

### 六大雷區
1. 凡事自己來（身先士卒型）
2. 急著證明自己（盲目改革型）
3. 不敢得罪人（尋求認同型）
4. 夾心餅乾（逃避責任型）
5. 怕被部屬取代（防衛型）
6. 迴避衝突（粉飾太平型）

## 部署方式

### 1. Fork 或 Clone 這個 Repository

### 2. 部署到 Vercel
1. 到 [vercel.com](https://vercel.com)，登入後點 **Add New Project**
2. Import 這個 GitHub Repository
3. 直接點 **Deploy**（不需要任何設定）
4. 部署完成，取得你的專屬網址

### 3. 使用方式
打開網頁後，在頂部輸入你的 **Anthropic API Key**（格式：`sk-ant-...`），點確認後即可開始對話。

> API Key 儲存在瀏覽器本地，不會上傳到任何伺服器。

## 取得 API Key
前往 [console.anthropic.com](https://console.anthropic.com) 註冊並取得 API Key。
